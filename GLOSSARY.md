# Portfolio glossary

| Term | Meaning |
| --- | --- |
| Project | An implemented personal software project, described by one content record and supported by reproducible evidence. |
| Category | A primary area of work. Each project belongs to one category; tags describe overlapping topics. |
| Featured project | The single published representative selected for a category on the homepage, by a pin or stable date ordering. |
| Collection | The published project catalogue with category, search and sort controls. |
| Case study | A project's context, implementation decisions, verification, reproduction steps and limitations. |
| Standard case | A case study rendered from structured content without new presentation code. |
| Specialised case | A case study with a project-specific evidence interaction or experiment presentation. |
| Evidence report | A saved result from a reproducible project run, not a live device connection. |
| Diagnostic scenario | One simulated response or failure condition and its expected observation. |
| Test outcome | Whether the observed diagnostic matched the expectation; a detected fault can be a passing test. |
| Profile | Confirmed personal, education, availability, work-rights and contact information shared by the site's presentation. |
| Future direction | An explicitly unimplemented idea, kept separate from published projects. |
